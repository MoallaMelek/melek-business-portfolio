# Client demo quality checklist

- [ ] Verify the portfolio and each demo on mobile and desktop.
- [ ] Check keyboard navigation, readable contrast, and image alternative text.
- [ ] Test QR destinations from an actual phone camera.
- [ ] Verify menus and prices against the prospect's latest public information before a pitch.
- [ ] Label conceptual checkout, loyalty, or booking flows as demonstrations until operational.
- [ ] Confirm all public links and contact actions work after deployment.
- [ ] Preserve font licenses and image usage permissions.

Do not imply that an uncommissioned prospect concept is an official client website.
