# Melek Moalla — Business Portfolio

Client-facing portfolio presenting websites and QR menus for small businesses, with an interactive sample menu and hosted demonstrations.

**Live site:** https://melek-business.vercel.app

Built with HTML, CSS, and JavaScript. Overdozz and Bol & Miette are independent prospect demonstrations, not commissioned client projects. Booking and catalog interactions are demonstrations.

## Run locally

Use Node.js 22 and npm.

```sh
npm ci
npm start
```

Open http://localhost:4173. The sample menu is at `/menu`; demonstrations are at `/demos/overdozz` and `/demos/bol-miette`.

The static files are served directly; no build step or environment variables are required. Keep the font license files in `assets/` when distributing the project.
